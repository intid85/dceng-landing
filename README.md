# DCENG 덕천산업 — 회사 소개 랜딩페이지

1985년 설립 이후 스테인리스(SUS) 탱크, 열교환기, 건조기, 믹서 등을 외주제작해 온
덕천산업의 회사 소개 랜딩페이지입니다.

## 페이지 구성

- **히어로** — 브랜드 타이포 + 현장 사진 마퀴 스트립
- **회사소개** — 설립 연도, 납품 업체 수, 최장 거래 기간
- **제작 품목** — 탱크 / 열교환기·믹서 / 건조기 / 부품·프레임·지그 (호버 인터랙션)
- **품질관리** — RT 방사선투과검사, LT 누설검사(수압 3KG+ / 공기압 3~5KG)
- **거래처** — 주요 거래처 목록 및 거래 실적
- **현장 갤러리** — 제작·설치 현장 사진
- **견적 문의** — 문의 내용 클립보드 복사 폼

## 기술 스택

- React 19 + TypeScript + Vite
- Tailwind CSS (shadcn/ui 기반 템플릿)
- Rajdhani(디스플레이) + Pretendard(본문) 웹폰트

## 로컬 실행

```bash
npm install
npm run dev     # 개발 서버
npm run build   # 프로덕션 빌드 (dist/)
```

## ⚠️ 사진 파일 안내 (중요)

`src/assets/` 의 제품·현장 사진 19점은 저장소에 포함되어 있지 않습니다.
(저작권이 있는 회사 자료이므로 필요시 회사에서 제공한 원본 파일을 넣어주세요.)

1. 저장소 페이지에서 **Add file → Upload files** 선택
2. `src/assets/` 경로로 이동 후 사진 19점을 드래그 앤 드롭
3. Commit changes

사진이 없으면 빌드는 실패합니다(소스에서 `import` 하고 있음).

## 비고

- 사진 자료는 회사 홍보 PPT(덕천산업 회사홍보자료)에서 제공받은 것을 사용했습니다.
- 문의 폼은 연락처 확정 전까지 클립보드 복사 방식으로 동작합니다.
- `package-lock.json` 은 저장소에 포함하지 않았습니다. `npm install` 로 재생성됩니다.
